# TOP 10 GIER — Hall of Fame 🏆

A university project for the Web Technologies course (*Technologie Webowe*).

👉 **[nadludyna.github.io/top10gier](https://nadludyna.github.io/top10gier/)**

My personal ranking of the ten best games ever. The code was largely written by AI, but the list and the reviews are 100% my own opinion, and I'll defend it to the end.

The site itself is in **Polish**, since it was made for a Polish university course.

> *Rzeczywistość ma kiepską fabułę, straszny grind i jest pay-to-win. Dlatego wybrałem inną drogę.*
> (Reality has a bad plot, a terrible grind, and it's pay-to-win. So I chose another way.)

## The ranking

| Tier | Games |
|------|-------|
| Emerald 🟢 | F.E.A.R., Dark Souls: Remastered |
| Diamond 💎 | SOMA, Neon White, Hades, Metro Exodus |
| Gold 🟡 | Silent Hill 2, Darkwood, Fallout: New Vegas, Half-Life |

Click a game card to open a preview with a review (a bit less serious than it should be), pros, cons, a one-line verdict and a Steam link. Each preview takes on the color of its tier.

## What's on the page

- ⌨️ A typewriter intro
- 📚 A fake "library loading" bar on the first screen: covers of all 10 games light up one by one in their tier colors, and you can click any of them to open its preview (with `prefers-reduced-motion` it just shows everything at once)
- 🃏 Game cards that open a preview window (close it with ×, a click outside, or Esc; focus goes back to where you were)
- 📧 A newsletter form that says thanks but doesn't actually save or send anything — there's no backend, it's a course project
- ⬆️ A back-to-top button and a header that hides while you scroll down
- 🎨 A hand-made logo in `grafika/samodzielna_grafika/`
- 🐈 Schrödinger's cat in the bottom-left corner — try to catch it

## Tech

No frameworks, no build step, no `node_modules` — just HTML, CSS and vanilla JavaScript. The only external thing is the Rajdhani font from Google Fonts.

```
index.html     — the whole page (one-page site)
style.css      — styles
script.js      — game data (the GAMES object) and all the logic
favicon.ico    — favicon
grafika/
  glowna/               — avatar and tier icons
  karteczki/            — images on the game cards
  gry/                  — artwork shown in the game preview
  ikona/                — favicon and touch icons
  samodzielna_grafika/  — logo
```

To run it, just open `index.html` in a browser. The live version is hosted on GitHub Pages.

To change the ranking, edit the `GAMES` object in `script.js` (text, pros/cons, Steam link) and the cards in `index.html` (which tier a game sits in).
